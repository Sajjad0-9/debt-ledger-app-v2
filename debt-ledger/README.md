# تطبيق «سجل الديون» - المرحلة الأولى

تطبيق ويب عربي خفيف ومتجاوب بالكامل، صُمم خصيصاً لإدارة ديون ومبيعات الزبائن للمحلات والأنشطة التجارية في العراق والوطن العربي، مع اعتماد **الدينار العراقي (د.ع)** كعملة افتراضية أساسية.

---

## 🌟 مميزات المرحلة الأولى

1. **تصميم عربي أصيل (RTL):** واجهة هادئة ومريحة للعين بخلفية فاتحة وخطوط واضحة، متجاوبة 100% مع الهواتف والحواسيب.
2. **تجربة مخصصة للأجهزة:**
   - **على الهاتف المحمول:** شريط تنقل سفلي سريع وسهل الوصول بإبهام اليد، ونماذج إدخال وأزرار لمس كبيرة وواضحة (ارتفاع لا يقل عن 48px).
   - **على الكمبيوتر:** قائمة جانبية ثابتة ومريحة لاستعراض البيانات والشاشات.
3. **الأزرار السريعة الأساسية:**
   - **إضافة زبون:** نافذة فورية لإضافة اسم وهاتف وعنوان الزبون.
   - **بيع بالأجل:** فاتورة متعددة المنتجات مع حساب تلقائي لإجمالي كل مادة وإجمالي الفاتورة، وتاريخ قابل للتعديل.
   - **تسجيل تسديد:** تسجيل دفعات نقدية أو عبر زين كاش مع خصم مباشر وفوري من دين الزبون.
   - **عرض كشف الحساب:** جدول تفصيلي يوضح الحركات (مدين / دائن / الرصيد المتبقي) مع إمكانية الطباعة والمشاركة المباشرة عبر واتساب.
4. **محرك تخزين محلي ذكي (LocalStorage):** يعمل مباشرة وبشكل فوري دون الحاجة إلى خادم أو اتصال إنترنت، مع ميزة تصدير واستيراد النسخ الاحتياطية بصيغة JSON.
5. **تطبيق ويب تقدمي (PWA):** قابل للتثبيت كأيقونة تطبيق مستقل على شاشة هاتف الأندرويد أو الحاسوب بفضل ملف `manifest.webmanifest` و`sw.js`.
6. **أمان تام:** لا يحتوي على أي مفاتيح سرية أو كلمات مرور في الواجهة الأمامية.

## 🚀 كيفية فتح التطبيق واختباره من هاتف أندرويد

بما أن المشروع مبني بأبسط وأقوى بنية قياسية (HTML5 / CSS3 / ES6 Vanilla)، فلن تحتاج إلى أي أدوات طرفية أو تثبيت Node.js على هاتفك:

### الطريقة الأولى: الفتح المباشر عبر متصفح الهاتف (الأسهل فوراً)
1. فك ضغط ملف `debt-ledger-app.zip` على هاتفك باستخدام أي تطبيق لإدارة الملفات (مثل **Files by Google** أو **ZArchiver**).
2. افتح المجلد واضغط على ملف `index.html`.
3. اختر فتحه عبر متصفح Chrome أو Samsung Internet أو أي متصفح لديك. سيعمل التطبيق بكامل وظائفه فوراً.

### الطريقة الثانية: عبر تطبيقات محررات الويب على أندرويد (تمنحك خادم محلي كامل)
- قم بتثبيت أحد التطبيقات المجانية التالية من متجر Google Play:
  - **Acode - code editor** أو **TrebEdit**.
- افتح مجلد `debt-ledger` واضغط زر التشغيل (Play ▶). سيعمل التطبيق على عنوان محلي مثل `http://localhost:8080` مع دعم ميزات PWA كاملة.

## ⚖️ ما يعمل فعلياً في هذه المرحلة وما هو واجهة أولية

| العنصر / الوظيفة | الحالة في المرحلة الأولى | الملاحظات التقنية |
| :--- | :---: | :--- |
| **إضافة وبحث الزبائن** | يعمل فعلياً 100% | تحفظ البيانات في LocalStorage مع أرقام الهاتف والعناوين |
| **إنشاء فواتير بيع متعددة المواد** | يعمل فعلياً 100% | حساب ديناميكي للإجمالي وترحيل فوري للرصيد بالدينار العراقي |
| **تسجيل التسديدات والدفعات** | يعمل فعلياً 100% | يخصم المبلغ فوراً من دين الزبون ويسجل التاريخ وطريقة الدفع |
| **كشف حساب الزبون التراكمي** | يعمل فعلياً 100% | حساب دقيق لـ (مدين / دائن / الرصيد بعد الحركة) مع زر واتساب والطباعة |
| **سجل الحركات والتصفية** | يعمل فعلياً 100% | تصفية حسب التاريخ، النوع (فواتير/تسديدات)، أو الزبون |
| **النسخ الاحتياطي والاستعادة** | يعمل فعلياً 100% | تصدير واستيراد ملف JSON بالكامل لحماية بياناتك من الضياع |
| **التثبيت كتطبيق PWA** | يعمل فعلياً 100% | جاهز مع Service Worker وأيقونات متوافقة مع أندرويد |
| **واجهة تسجيل الدخول (Auth)** | واجهة مكتملة + وضع تجريبي | تحاكي الدخول عبر Google أو رقم الهاتف، وجاهزة للربط مع Firebase Auth |
| **المزامنة السحابية وقاعدة البيانات** | محلي حالياً (LocalStorage) | جاهز للربط في المرحلة الثانية عبر Cloud Firestore |
