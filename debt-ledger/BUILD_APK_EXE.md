# مسار تحويل التطبيق إلى ملف APK لأندرويد و EXE لويندوز

تطبيق «سجل الديون» مبني وفق معايير **PWA (Progressive Web App)** القياسية العالمية، مما يجعله قابلاً للتحويل المباشر إلى تطبيق نظام أصلي (Native App) على أندرويد وويندوز بأكثر من طريقة، من بينها طرق تعمل مباشرة من الهاتف دون الحاجة لأي حاسوب!

---

## أولاً: تحويل التطبيق إلى ملف APK لأندرويد

### 1. المسار الأول: عبر PWABuilder (أداة مايكروسوفت الرسمية - مجاني وبدون كمبيوتر)

هذه هي الطريقة الأسهل والأسرع والتي يمكنك القيام بها من متصفح هاتفك المحمول مباشرة:

1. انشر تطبيقك على رابط HTTPS (كما هو موضح في ملف `DEPLOYMENT_GUIDE.md`).
2. ادخل من هاتفك إلى موقع: [https://www.pwabuilder.com](https://www.pwabuilder.com).
3. ضع رابط موقعك المنشور واضغط **Start**.
4. سيقوم الموقع بفحص ملف `manifest.webmanifest` و`sw.js` اللذين قمنا بإعدادهما، وسيعطيك تقييماً كاملاً باللون الأخضر.
5. اضغط على **Package for Stores** واختر **Android**.
6. يمكنك تنزيل ملف **APK** وتثبيته مباشرة على هاتفك أو حزمة **AAB** لرفعها إلى متجر Google Play.

### 2. المسار الثاني: عبر إطار عمل Capacitor (Native Android Project)

إذا توفر لديك كمبيوتر لاحقاً وأردت بناء مشروع أندرويد ستوديو كامل مع إمكانية الوصول إلى ميزات العتاد العميق (مثل البلوتوث للطابعات الحرارية المحمولة):

1. قم بتثبيت Capacitor:
   ```bash
   npm init @capacitor/app
   npm i @capacitor/android
   npx cap add android
   ```
2. ضع ملفات المشروع (`index.html`, `css`, `js`, `icons`, `manifest`) داخل مجلد `www/`.
3. شغّل الأمر:
   ```bash
   npx cap sync
   npx cap open android
   ```
4. سيفتح مشروع Android Studio ويمكنك توليد ملف `app-release.apk`.

## ثانياً: تحويل التطبيق إلى ملف EXE أو MSIX لنظام Windows

### 1. المسار الأول: عبر PWABuilder (الأسرع والأسهل)
- في موقع [PWABuilder](https://www.pwabuilder.com)، بعد إدخال الرابط، اختر **Windows**.
- سيقوم بتوليد حزمة MSIX قابلة للتثبيت بنقرة واحدة على Windows 10 و Windows 11.

### 2. المسار الثاني: عبر Electron
- يمكن تغليف مجلد التطبيق في ملف `package.json` وتشغيل `electron-packager` لتوليد ملف `DebtLedger.exe` مستقل تماماً لا يحتاج لأي متصفح إنترنت.

### 3. المسار الثالث: عبر Tauri (الخيار فائق الخفة)
- باستخدام إطار Tauri، يتم إنتاج ملف `exe` خفيف جداً بحجم لا يتجاوز 3 إلى 5 ميجابايت مع استهلاك فائق الصغر للذاكرة.
